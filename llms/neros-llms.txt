# Neros

> Neros Technologies is an American defense manufacturer (founded 2023, El Segundo, California) that designs and mass-produces low-cost, attritable FPV drones and ground control stations for Western military forces. Neros publishes no public web API. Its machine-readable interface contribution is APEX (Adaptive Payload EXchange) — an open, MIT-licensed, plug-and-play UART protocol and mechanical connector standard for drone host/payload interoperability, with a C99 reference implementation and a hardware development kit on GitHub.

Generated by the API Evangelist enrichment pipeline on 2026-08-04 from apis.yml and the artifacts in this repository. Neros does not publish an llms.txt of its own (https://www.neros.tech/llms.txt returned 404).

## What Neros ships

- ARCHER — FPV drone built for modular payloads and resilient comms; mass produced with a secured supply chain, on the DIU Blue UAS Cleared List
- ARCHER STRIKE — kinetic-enabled FPV for effects at range in contested environments
- CROSSBOW — tactical ground control station built for electronic-warfare resistance at range
- LONGBOW — maximum-range ground control station for stationary positions

## APIs

- [APEX — Adaptive Payload EXchange](https://github.com/Neros-Technologies/APEX): Open plug-and-play UART protocol connecting drone hosts and payloads over a standard 10-pin connector. Class-agnostic core (COBS framing, 4-byte outer header, CRC-16/CCITT-FALSE, three-leg discovery handshake, capability exchange, device lifecycle) plus extensible device classes. Protocol version V0; specification snapshot v0.8.0; status Draft. It is a UART wire protocol — there is no base URL, no hosted endpoint, and no authentication scheme.

## Notes for agents

- There is no Neros HTTP API, no OpenAPI, no GraphQL endpoint, no MCP server and no A2A agent card. api.neros.tech, docs.neros.tech, developer.neros.tech and status.neros.tech do not resolve in DNS.
- Neros' own product documentation sits at https://www.neros.tech/protected-downloads and returns HTTP 401 — it is customer-only.
- APEX is a Draft specification. The specification documents and the C reference library are versioned together; the current snapshot is in VERSION.txt.
- APEX V0 defines no authentication, authorization or encryption. The trust boundary is the physical connector.
